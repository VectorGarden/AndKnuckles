Timebase
GIF delays are whole centiseconds, so it can hit PAL exactly (100 frames at 2cs = 2.00s) but can only approximate NTSC by resampling to 83 frames (1.66s). APNG delays are a fraction, so it expresses 59.92 Hz exactly as 100/5992 — pick APNG if the timing matters. Video is a real-time capture and is approximate either way.
Defaults are read from Obj_TitleBanner_Main in the Sonic 3 & Knuckles disassembly: 96px entry, 4px/frame initial velocity, 0.25px/frame² spring, velocity halved on each zero crossing. Stock values settle in 100 frames.
GIF and APNG are exact and lossless. WebM and MP4 are lossy real-time captures — WebM keeps transparency, MP4 does not (H.264 has no alpha, so transparent areas go black; pick a background colour first).
